# Circular Queue — Java

A simple implementation of a **Circular Queue using an Array in Java**. The circular queue efficiently reuses the empty spaces created after elements are removed.

## Concepts Used

* Queue
* Circular Queue
* Arrays
* FIFO (First In, First Out)
* Front and Rear
* Modulo Operation
* Object-Oriented Programming
* Java Classes and Objects

## Operations

The circular queue supports the following operations:

* `enqueue()` — Adds an element to the rear of the queue
* `dequeue()` — Removes an element from the front of the queue
* `peek()` — Returns the front element
* `isEmpty()` — Checks whether the queue is empty
* `isFull()` — Checks whether the queue is full
* `display()` — Displays the elements of the queue

## Key Feature

Unlike a normal linear queue, a circular queue allows the rear to wrap around to the beginning of the array and reuse available spaces.
